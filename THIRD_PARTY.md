# Third-party assets

`svg-icon-agent` does not ship SVG Repo artwork.

SVG files downloaded with the CLI are third-party assets and are not covered by this repository's MIT license. The CLI writes a `.svg.source.json` sidecar containing the source page and detected license. The individual SVG Repo icon page is the source of truth for that asset's listed license.

This project is not affiliated with or endorsed by SVG Repo LLC.
